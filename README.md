# 🎄 Advent of Code

My journey through [Advent of Code](https://adventofcode.com/) using **TypeScript**.

The goal is to rebuild my programming skills, improve my problem-solving abilities, and learn something new with every puzzle.

## 🛠️ Tech Stack

- TypeScript
- Node.js
- tsx

## 🚀 Usage

Install dependencies:

```bash
npm install
```

Run a solution:

```bash
npx tsx 2015/day01/solution.ts
```

Personal puzzle inputs are excluded from this repository.
